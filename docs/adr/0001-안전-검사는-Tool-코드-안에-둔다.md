# 안전 검사는 Hook이 아니라 Tool 코드 안에 둔다

사내 서버에서는 우리가 만든 코드가 LLM API를 직접 호출해 아이템을 실행하고, Claude Code Hook은 Claude Code 안에서만 동작한다. 그래서 대상 PC 확인, 설정 키 허용 목록, 백업 같은 안전 검사를 Tool 코드 안에 넣어, 어디서 실행하든 같은 검사가 걸리게 했다. Hook은 과제 양식에서 선택 항목이므로 쓰지 않거나, 쓰더라도 같은 검사 코드를 호출하는 개발 환경용 보조 장치로만 둔다.

## Considered Options

- **Hook으로 차단**: 서버 실행 환경에서는 Hook이 없어 검사가 사라진다. 기각.
