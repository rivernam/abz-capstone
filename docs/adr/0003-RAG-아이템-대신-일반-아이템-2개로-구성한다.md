# RAG 아이템 1개 대신 일반 아이템 2개로 구성한다

두 업무(일일 현황 리포트, 문의 대응)는 입력과 산출물과 쓰는 사람이 다르다. 문의 대응의 핵심도 문서 검색이 아니라 PC 정보 조회, 로그 확인, 설정 수정, 재시작 같은 Tool 동작이다. 그래서 RAG 아이템 1개(개선 3차 이상) 대신 일반 아이템 2개(각 개선 1차)로 구성했다. 일반 아이템은 RAG를 쓰지 않으므로 오류 원인은 오류 메시지 패턴표와 가이드로 판단하고, 개선 단계에서 클라이언트 소스를 문자열로 검색하는 Tool을 더한다.

## Considered Options

- **RAG 아이템 1개(두 업무 합침)**: 입력이 두 종류가 되고 단계가 7개 이상으로 늘며, RAG가 핵심 단계가 되지 못한다. 기각.
