# 주문 취소 처리

## 순서

1. `get_order`로 주문 상태를 확인한다.
2. 상태가 "결제완료"이면 `cancel_order`로 취소한다.
3. 상태가 "배송중"이면 취소할 수 없다. 취소 Tool을 부르지 말고, 상품을 받은 뒤 반품을 신청하도록 안내한다.

## 안내 문구

- 환불은 취소한 날부터 영업일 기준 3일 안에 결제 수단으로 돌아간다.
- 환불 금액은 `cancel_order` 결과의 `refund` 값을 그대로 쓴다. 직접 계산하지 않는다.
- 반품 신청은 상품을 받은 날부터 7일 안에 할 수 있다.
